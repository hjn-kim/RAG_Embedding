# RunPod PyTorch 템플릿의 torch 는 2.4.1 이다. 상한 없이 설치하면 최신

# import DTensor` 를 하고 그 공개 경로는 torch 2.5 부터 생겼다. 결과는
#   ImportError: cannot import name 'DTensor' from 'torch.distributed.tensor'
# 로 모든 모델 로드가 실패. 아래 조합은 torch 2.4.x 에서 검증된 값이다.
# huggingface-hub 1.x 는 transformers 4.46 과 호환되지 않으므로 함께 묶는다.
# 템플릿 torch 가 2.5 이상으로 올라가면 이 상한을 풀어도 된다.
sentence-transformers==3.3.1

accelerate==1.1.1
huggingface-hub>=0.26.0,<1.0

# BGE-M3 hybrid(dense+sparse) 평가용. 설치 실패해도 dense 단독으로는 동작함.
# 1.3.2 로 고정하는 이유: 최신 FlagEmbedding 은 모델 로드 때 dtype= 을 넘기는데
# 그 인자명은 transformers 4.56 부터다(그 전에는 torch_dtype=). 위에서 4.46.3 에
# 묶여 있으므로 최신을 쓰면
#   TypeError: XLMRobertaModel.__init__() got an unexpected keyword argument 'dtype'
# 로 BGE-M3 만 조용히 실패하고 표에서 두 행이 통째로 빠진다.
